## 第1章：システム概要

### 1.1 プロジェクト情報

#### プロジェクト基本情報

| 項目 | 内容 |
|------|------|
| **プロジェクト名** | JUXYI Content Management System |
| **プロジェクトコード** | JUXYI-CMS |
| **対象地域** | 日本国内 |
| **想定ユーザー数** | 10,000+ ユーザー |
| **開発体制** | 小規模チーム（< 10 名） |
| **開発期間** | 2024 Q4 - 2025 Q2 |
| **予算** | 月額運用コスト: ¥70,500（Azure リソース） |

#### システム目的

本システムは、日本国内ユーザー向けに**コンテンツ（ドキュメント・ビデオ・URL リンク）の管理・配信**を行うプラットフォームです。

**主要目的**：
1. ✅ 管理者がコンテンツを作成・編集・公開
2. ✅ モバイルアプリユーザーがコンテンツを閲覧
3. ✅ プッシュ通知でユーザーにコンテンツ配信
4. ✅ 集章活動（QR コードスタンプラリー）機能
5. ✅ マイページ Web との SSO 統合

#### ビジネス価値

| ステークホルダー | 提供価値 |
|----------------|---------|
| **エンドユーザー** | ・スマートフォンでいつでもコンテンツ閲覧<br>・集章活動によるエンゲージメント向上<br>・マイページとのシームレスな連携 |
| **管理者** | ・直感的な管理画面<br>・効率的なコンテンツ配信<br>・プッシュ通知による即時配信 |
| **経営層** | ・ユーザーエンゲージメント向上<br>・運用コスト削減（クラウド活用）<br>・スケーラブルなインフラ |

**システム間連携**：

| 連携元 | 連携先 | 連携方式 | 用途 |
|-------|-------|---------|------|
| Mobile App | マイページAPI | WebView + postMessage | 初回ログイン認証 |
| Mobile App | CMS API | REST API (JWT) | コンテンツ取得 |
| Mobile App | Azure Blob Storage | 直接アクセス | ビデオ・PDF ダウンロード |
| Mobile App | マイページ Web | SSO (Ticket) | 外部ブラウザ連携 |
| Web 管理画面 | CMS API | REST API (JWT) | コンテンツ管理 |
| CMS API | Azure Notification Hubs | SDK | プッシュ通知送信 |
| マイページAPI | CMS API | 内部 API | JWT 秘密鍵共有なし（環境変数） |

#### Monorepo 管理戦略

**ブランチ戦略（Git Flow）**：

```
main (本番)
  └── develop (開発)
       ├── feature/auth-implementation
       ├─�� feature/content-management
       ├── feature/push-notification
       └── hotfix/security-patch
```

**ブランチ命名規則**：

| ブランチタイプ | 命名形式 | 例 |
|--------------|---------|-----|
| Feature | `feature/{機能名}` | `feature/auth-implementation` |
| Bugfix | `bugfix/{バグ名}` | `bugfix/login-validation` |
| Hotfix | `hotfix/{修正内容}` | `hotfix/security-patch` |
| Release | `release/v{バージョン}` | `release/v1.0.0` |

**コミットメッセージ規約（Conventional Commits）**：

```
<type>(<scope>): <subject>

<body>

<footer>
```

| Type | 説明 | 例 |
|------|------|-----|
| **feat** | 新機能追加 | `feat(auth): add e-ninsho authentication` |
| **fix** | バグ修正 | `fix(api): fix JWT token expiration` |
| **docs** | ドキュメント変更 | `docs(architecture): update system diagram` |
| **style** | コードスタイル変更 | `style(frontend): format with prettier` |
| **refactor** | リファクタリング | `refactor(service): extract validation logic` |
| **test** | テスト追加・修正 | `test(auth): add unit tests for login` |
| **chore** | ビルド・設定変更 | `chore(deps): update dependencies` |

**プルリクエストテンプレート**：

```markdown
## 変更内容
<!-- 何を変更したか簡潔に記載 -->

## 変更理由
<!-- なぜこの変更が必要か -->

## テスト内容

- [ ] 統合テスト実施
- [ ] 手動テスト実施

## チェックリスト
- [ ] コードレビュー済み
- [ ] ドキュメント更新済み
- [ ] Breaking Changes なし

## スクリーンショット（UI変更の場合）
<!-- 変更前後のスクリーンショット -->
```
